## Supported route for Studio's current anonymous attach

Use the native **desktop preview callbacks**, not the authenticated browser controller. Studio already creates sessions with `source: 'desktop'`; Hermes folds `desktop_ui` into desktop-sourced sessions and injects `read_preview_callback` and `drive_preview_callback`. No extra runtime config, tool catalog or agent executor is necessary. [Studio session creation](../../desktop/hermes/bridge.mjs), [Hermes source gate](/Users/luca/.hermes/hermes-agent/tui_gateway/server.py:1974), [injected callbacks](/Users/luca/.hermes/hermes-agent/tui_gateway/agent_callbacks.py:141), [native toolset](/Users/luca/.hermes/hermes-agent/toolsets.py:139).

The native public agent tools are `desktop_preview` (`open`, `close`, `read`), `drive_preview` and `annotate_preview`. `browser_*` is a separate automated browser family; connecting preview callbacks does not make `browser_snapshot` control this page. [Preview schema](/Users/luca/.hermes/hermes-agent/tools/preview_tool.py:44), [drive schema](/Users/luca/.hermes/hermes-agent/tools/drive_preview_tool.py:80).

Advertise per live gateway connection:

```json
{"jsonrpc":"2.0","id":1,"method":"client.capabilities","params":{"server_requests":true}}
```

The result includes `server_requests: string[]` and `declines_not_shown: true`. Advertise only once an actual surface/request handler exists, and withdraw when no handler remains. The advertisement describes the whole transport's ability to answer requests, not controller ownership. ### Requests, responses and events

Current wire transport is bidirectional JSON-RPC. Older docstrings referring to `preview.read.request` / `preview.read.respond` and `preview.act.request` / `preview.act.respond` are stale; do not implement those invented methods. [Current authoritative transport](/Users/luca/.hermes/hermes-agent/tui_gateway/server_requests.py:1).

```json
{"jsonrpc":"2.0","id":"srq-012345abcdef","method":"preview.read","params":{"session_id":"runtime-session","start":0,"count":24000}}
{"jsonrpc":"2.0","id":"srq-012345abcdef","result":{"value":"{\"kind\":\"url\",\"url\":\"https://example.test/\",\"title\":\"Test\",\"text\":\"Visible page text\",\"start\":0,\"end\":17,\"total_chars\":17}"}}
```

`start` is a zero-based character offset, `count` is characters requested; upstream default and cap are 24,000. The extraction is the visible page's `innerText`, actual title and actual URL. Optional metadata: `path`, `note`, `active_tab_id`, `tabs: [{id,kind,label,url}]`. Return `value: ''` when no page is open, or a JSON failure with a concrete reason. [Read request contract](/Users/luca/.hermes/hermes-agent/tui_gateway/contracts/server_requests.py:150), [native reader result/windowing](/Users/luca/.hermes/hermes-agent/apps/desktop/src/app/chat/right-rail/preview-reader.ts:36), [value unwrapping](/Users/luca/.hermes/hermes-agent/tui_gateway/server.py:1393).

```json
{"jsonrpc":"2.0","id":"srq-abcdef012345","method":"preview.act","params":{"session_id":"runtime-session","action":"click","ref":"btn-sign-in"}}
{"jsonrpc":"2.0","id":"srq-abcdef012345","result":{"value":"{\"success\":true,\"acted\":\"btn-sign-in\",\"url\":\"https://example.test/next\",\"title\":\"Next\",\"elements\":[{\"ref\":\"btn-continue\",\"role\":\"button\",\"label\":\"Continue\"}]}"}}
```

Action fields: `action`, `ref`, `selector`, `text`, `key`, `submit`, `full`, `to`, `amount`, `max`, `allow_shortcut`; known tool verbs: `elements`, `click`, `hover`, `type`, `scroll`, `press`, `strobe`, `back`, `forward`, `reload`. `type` needs text (empty text clears); `press` needs key; click/hover/type/press need ref or selector; `scroll` needs no target, `to` is `top` or `bottom`. `max` is the wire name; Python function maps `limit` to `max`. Reply value is JSON containing `success`, actual `url`/`title`, optional `acted`, `elements`, `delta`, `error`, `note`. Ref inventory nodes have `{ref,role,label,selector?,value?,disabled?}`. Refs survive rerenders and retire on navigation; delta fields are `added`, `changed`, `removed`, `rebound`, `same`. [Request shape](/Users/luca/.hermes/hermes-agent/tui_gateway/contracts/server_requests.py:167), [tool validation](/Users/luca/.hermes/hermes-agent/tools/drive_preview_tool.py:28), [native result and delta types](/Users/luca/.hermes/hermes-agent/apps/desktop/src/lib/preview-act/types.ts:88).

`desktop_preview action=open` emits gateway event `{type:'preview.open', session_id, payload:{url,label}}`; close emits `preview.close` with `{url}` (empty means whole pane). Open is **fire-and-forget**: Hermes tool success means the event was emitted, not that the page finished loading. Studio navigation receipts must await real load outcome. Do not claim stronger native acknowledgement. [Open implementation](/Users/luca/.hermes/hermes-agent/tools/open_preview_tool.py:82), [close implementation](/Users/luca/.hermes/hermes-agent/tools/preview_tool.py:16), [event contracts](/Users/luca/.hermes/hermes-agent/tui_gateway/contracts/events.py:575).

`request.cancel` withdraws an exact server request ID on timeout/interruption/shutdown/close. It is delivered as a gateway event; stop queued input and suppress late replies. `session.resume`/`activate`/`events.since` may return `open_requests`; do not repeat mutating actions on replay. First act probe is 10s, established bridge budget 45s, unanswered reprobe cooldown 30s. [Cancellation/replay](/Users/luca/.hermes/hermes-agent/tui_gateway/server_requests.py:1), [preview timeout ladder](/Users/luca/.hermes/hermes-agent/tui_gateway/server.py:1465).

Window ownership matters: unknown or foreign sessions cannot access the browser. A client with no window showing a session declines with JSON-RPC `error:{code:4404,message:...}`; newer backend settles only once all attached answering clients decline. Send this special decline only when advertised `declines_not_shown` is true. Even a hosted background session must be refused for mutations unless it is the selected session. [Decline contract](/Users/luca/.hermes/hermes-agent/tui_gateway/server_requests.py:100), [native selected-session action gate](/Users/luca/.hermes/hermes-agent/apps/desktop/src/app/session/hooks/use-message-stream/gateway-event/server-requests.ts:527).

## Why controller registration is unsupported here

`browser.controller.register` requires literal enabled flag `browser.extension_control.enabled`, protocol version integer `1`, attached session, server-minted non-internal `{user_id,provider}`, server session profile and nonempty `controller_id`/`browser_profile_id`. Principal is computed by server digest; a caller-supplied principal cannot authenticate. Transport family is `cloud-ticket-ws`. Studio's anonymous session-token connection does not satisfy this authentication gate. Do not invent user identity, reuse `server-internal`, mutate personal config or register a fake controller. [Identity and membership gates](/Users/luca/.hermes/hermes-agent/tui_gateway/methods_browser_control.py:38), [register](/Users/luca/.hermes/hermes-agent/tui_gateway/methods_browser_control.py:149), [flag/protocol](/Users/luca/.hermes/hermes-agent/gateway/browser_control_broker.py:27), [internal identity](/Users/luca/.hermes/hermes-agent/hermes_cli/dashboard_auth/ws_tickets.py:28).

If an authenticated route is later selected, register params are `{session_id,protocol_version:1,controller_id,browser_profile_id,capabilities:[...]}`. Commands arrive as gateway events `browser.controller.command` with `{command_id,action,arguments,controller_id,browser_profile_id,tool_call_id}`. Exact owning transport answers RPC `browser.controller.result` with `{session_id,command_id,ok:true,result}` or `{...,ok:false,error}`; result returns `{accepted:boolean}`. Heartbeat/detach require same authenticated exact owner. Capability allowlist includes `controller.noop`, `browser_back`, `browser_click`, `browser_navigate`, `browser_press`, `browser_screenshot`, `browser_scroll`, `browser_snapshot`, `browser_tab_activate`, `browser_tabs`, `browser_type`; eval/raw CDP require explicit developer mode. This is a separate future route, not the chosen repair. [Broker command](/Users/luca/.hermes/hermes-agent/gateway/browser_control_broker.py:338), [result ownership](/Users/luca/.hermes/hermes-agent/tui_gateway/methods_browser_control.py:185), [capabilities](/Users/luca/.hermes/hermes-agent/gateway/browser_control_broker.py:31).

## Minimal Studio integration proposal

These are **proposed Studio internal APIs**, not Hermes RPC methods:

1. Main process owns a sandboxed `WebContentsView` (current Electron dependency 44.5.1), with a separate persistent partition keyed by connection/profile ownership. Persist tabs/history explicitly; do not trust partition alone to restore history. No UI token/header interception shared into browser partition. Native upstream preview uses `persist:hermes-preview`; choose stricter per-owner partitions for Studio's multi-host model. [Studio dependency](../../desktop/package.json), [existing main process isolation](../../desktop/electron/main.cjs), [upstream partition](/Users/luca/.hermes/hermes-agent/apps/desktop/src/app/chat/right-rail/preview-pane.tsx:1138).
2. Renderer preload exposes only `mount({threadId,tabId,bounds})`, `hide()`, navigation/tab operations and state subscription to the privileged Studio UI. Main verifies sender and Studio origin. No arbitrary code/CDP API exposed to the renderer or the guest page. Bound WebContentsView is the actual interactive surface the user sees.
3. Utility-process bridge resolves Hermes runtime session to an owned Studio thread, then sends main a private command `{id,connectionId,threadId,runtimeId,tabId,generation,method:'read'|'act',params}`. Main returns `{id,generation,result}`. Bridge responds to original `srq-*` with `{value:JSON.stringify(result)}` using existing `gateway.respond`. Gate/unknown/backend-disconnect failures return native failures; no timeout retries.
4. Browser operations use actual page DOM inventory to resolve references and real Chromium input for pointer/keyboard; read and actions share the same WebContents. `executeJavaScript` for fixed DOM extraction/target measurement is internal; `sendInputEvent` performs actions. Verify target identity, current navigation generation, selected owner and holder immediately before **each** input. Upstream separates look/resolve from input and witnesses trusted pointer input to avoid false success. [Native engine architecture](/Users/luca/.hermes/hermes-agent/apps/desktop/src/app/chat/right-rail/preview-act.ts:1).
5. Takeover is Studio's real execution gate for this callback surface: invalidate outstanding generation, abort queued key sequences, deny future mutating callbacks until explicit Resume. Session switch/disconnect/close has the same invalidation. Do not claim a native Hermes lease changed: the callback route has no `browser.control.acquire` RPC. Read may remain available for the owned page; resumed agent should inventory again before mutation.
6. Consume `preview.open/close` for owned sessions only, and route to the session's page. Background work records an offer/receipt rather than changing the user's selected browser. The selected mode and native tool names must be visible so the user and model do not confuse this with another `browser_*` executor.

The existing `HermesBridge.serverRequest` accepts only approvals; extend that actual boundary, capability lease management and cancellation tracking. Do not bolt a generic browser REST action onto the model and call that native integration. [Existing transport request/reply](../../desktop/hermes/gateway.mjs), [bridge handler](../../desktop/hermes/bridge.mjs).

## Addendum — canonical Bot Chat resume source, 2026-10-13

For **new** canonical Bot Chat create, retain the existing `title:'Bot Chat'`, `hidden:true`, `follow_profile_config:true`, stable `idempotency_key` and `close_on_disconnect:false`, and add `source:'desktop'`. The source selects client surface tools; `follow_profile_config` selects model/settings inheritance and is a separate concern. [Create contract](/Users/luca/.hermes/hermes-agent/tui_gateway/contracts/sessions.py:118), [platform toolsets](/Users/luca/.hermes/hermes-agent/tui_gateway/server.py:1974).

For an **existing** owned canonical session, the exact supported resume parameters are:

```json
{"session_id":"owned-stored-session-id","source":"desktop","close_on_disconnect":false}
```

Include the profile only when required by the owning runtime routing; preserve stored session ID and profile ownership. Optional supported resume controls are `lazy`, `defer_history`, `omit_messages`, `eager_build`, `inline_images` and `cols`; these control hydration/build/transport, not tool authorization. Do **not** send `follow_profile_config` on resume: it is absent from `SessionResumeParams`. Hermes restores that marker from persisted model config (or canonical `Bot Chat` title), preserving its native inheritance semantics. [Resume params](/Users/luca/.hermes/hermes-agent/tui_gateway/contracts/sessions.py:182), [stored marker restoration](/Users/luca/.hermes/hermes-agent/tui_gateway/methods_session.py:645), [marker/title predicate](/Users/luca/.hermes/hermes-agent/tui_gateway/server.py:1642).

Cold/deferred/eager resume calls `_Resume.mint()` → `_new_runtime_ids(params)` → `_resolve_session_source(params.source)`; the resulting live source reaches `_make_agent(... platform_override=source)`, enabling `desktop_ui` and callback injection. `client.capabilities {server_requests:true}` remains necessary on the attached transport so preview request round trips are answerable. No additional preview-specific capability register is required. [Source minting](/Users/luca/.hermes/hermes-agent/tui_gateway/methods_session.py:66), [resume mint](/Users/luca/.hermes/hermes-agent/tui_gateway/methods_session.py:638), [agent build](/Users/luca/.hermes/hermes-agent/tui_gateway/server.py:2670).

**Warm existing sessions are different:** `_resume_reuse_live_locked` and `_resume_live_unpersisted` reattach the transport and return the existing live record without applying `params.source`. `_live_session_payload` likewise does not change source/platform. Thus `source:'desktop'` on resume fixes a rebuild but cannot upgrade an already-live TUI session's toolsets. `session.activate` also only reattaches. A tool reload reuses the live agent's `platform`, so it is not a source upgrade either. No safe native source-upgrade RPC was found in these installed session/tool contracts. Do not close/recreate the canonical Bot Chat or restart its runtime merely to change its surface. Preserve the live work and report the actual available tools; desktop source takes effect when Hermes legitimately rebuilds that session.
